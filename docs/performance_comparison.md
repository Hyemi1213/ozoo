
## 모델 성능 비교

### 전체 정확도

| 모델 | Train Acc | Val Acc | Test Acc | 차이 |
|------|-----------|---------|----------|------|
| **XGBoost (표)** | 85.2% | 78.3% | **75.1%** | - |
| **CNN (이미지)** | 97.6% | 77.8% | **63.2%** | -11.9%p |
| **멀티모달** | 95.3% | 81.0% | **83.3%** | **+8.2%p** ✅ |

### 시각화

```
100% ┤
     │                 ●
 90% ┤              ●     ●
     │           ●
 80% ┤        ●           
     │     ●              
 70% ┤  ●                 
     │                    
 60% ┤              ●     
     │                    
 50% ┤
     └─────────────────────
       XGB   CNN   Multi
       (표) (이미지) (결합)
```

### 주요 발견

1. **멀티모달 > XGBoost > CNN**
   - 멀티모달이 가장 높은 성능
   - XGBoost 단독도 나쁘지 않음
   - CNN 단독은 데이터 부족

2. **과적합 문제**
   - CNN: Train 97.6% → Test 63.2% (과적합 심각)
   - 멀티모달: Train 95.3% → Test 83.3% (적절)

3. **일반화 성능**
   - 멀티모달이 가장 안정적
   - Train-Test 차이 최소

## 오류 분석

### False Positive (잘못된 생존 예측)

**XGBoost:**
```
실제 자연사 → 생존 예측: 2건
실제 안락사 → 생존 예측: 2건

원인: is_mixed=0 (순종견) → 무조건 생존 예측
```

**멀티모달:**
```
실제 자연사 → 생존 예측: 1건
실제 안락사 → 생존 예측: 2건

원인: 이미지상 건강해 보임
```

### False Negative (잘못된 안락사 예측)

**XGBoost:**
```
실제 생존 → 안락사 예측: 2건

원인: 나이 많음 + 믹스견
```

**멀티모달:**
```
실제 생존 → 안락사 예측: 1건

원인: 이미지가 불량 (흐릿함)
```

### 오류 케이스 예시

**Case 1: 나이든 순종견**
```
실제: 생존 (입양됨)
XGBoost: 생존 (is_mixed=0 때문)
CNN: 자연사 (나이들어 보임)
멀티모달: 생존 ✅

→ 멀티모달이 균형잡힌 판단
```

**Case 2: 어린 믹스견**
```
실제: 생존 (입양됨)
XGBoost: 안락사 (is_mixed=1 + 낮은 점수)
CNN: 생존 (귀여워 보임)
멀티모달: 생존 ✅

→ CNN이 순종견 편향 제거
```
