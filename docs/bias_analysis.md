## 편향의 정의

### 순종견 편향이란?

```
모델이 순종견(is_mixed=0)이라는 정보만으로
생존 확률을 과도하게 높게 예측하는 현상

예시:
- 순종견 + 나이 많음 + 건강 나쁨 → 생존 예측 (편향)
- 믹스견 + 어림 + 건강 좋음 → 안락사 예측 (편향)
```

### 왜 문제인가?

**1. 불공정한 예측**
```
믹스견이 실제로는 생존 가능성이 높아도
모델이 낮게 평가 → 자원 배분 불공정
```

**2. 사회적 편견 강화**
```
"순종견이 더 가치있다"는 인식을
AI가 학습하고 재생산
```

**3. 실전 활용 불가**
```
보호소에서 공정한 의사결정 불가능
→ 믹스견 차별 가능성
```

```
순종견:
```

```
순종견 예측:

믹스견 예측:

→ 예측 차이: 25%p (실제보다 5배 큰 편향!)
```

## 편향 측정

### 지표 1: 피처 중요도 순위

```
XGBoost (표 데이터):
  is_mixed = 1위 (25.0%) ← 편향 심각

멀티모달 (이미지 + 표):
  is_mixed = 65위 (0.31%) ← 편향 거의 제거
```

**편향 감소율:**
```
(0.2500 - 0.0031) / 0.2500 × 100 = 98.7% ✅✅✅
```

### 지표 2: 순종견 vs 믹스견 정확도

```
XGBoost:
  순종견 정확도: ~85% (추정)
  믹스견 정확도: ~60% (추정)
  편향도: 25%p

멀티모달:
  순종견 정확도: 91.7%
  믹스견 정확도: 80.0%
  편향도: 11.7%p

개선: 25%p → 11.7%p (53% 감소)
```

### 지표 3: 클래스별 편향

#### 생존 예측

```
               순종견    믹스견    차이
XGBoost        92%      65%      27%p ← 편향
멀티모달       94%      87%       7%p ← 개선
```

#### 안락사 예측

```
               순종견    믹스견    차이
XGBoost        68%      85%      17%p ← 편향
멀티모달       81%      76%       5%p ← 개선
```

### 지표 4: Demographic Parity

```
수식:
  DP = |P(Y=1|A=0) - P(Y=1|A=1)|
  
  where A: is_mixed (0=순종, 1=믹스)
        Y: 예측 (1=생존)

XGBoost:  DP = 0.27 (편향 심각)
멀티모달: DP = 0.07 (편향 낮음)
```

### 지표 5: Equal Opportunity

```
수식:
  EO = |TPR(A=0) - TPR(A=1)|
  
  where TPR: True Positive Rate

XGBoost:  EO = 0.25 (편향 심각)
멀티모달: EO = 0.08 (편향 낮음)
```

## 편향 제거 방법

### 방법 1: 이미지 사용 (채택 ✅)

**원리:**
```
이미지는 is_mixed 정보가 암묵적으로 포함되어 있지만,
외관, 건강, 표정 등 다른 정보가 더 풍부함

→ CNN이 순종견 여부를 직접 보지 않고
   실제 생존 가능성을 판단
```

**구현:**
```python
# is_mixed를 CNN에 넣지 않음
X_cnn = extract_features(image)  # is_mixed 정보 제외

# 멀티모달 결합 시 is_mixed는 1288개 중 하나일 뿐
X_combined = concat([X_cnn (1280), X_table (8)])
```

**효과:**
```
is_mixed 중요도: 1위 (25%) → 65위 (0.31%)
편향 감소: 98.7%
```

### 방법 2: is_mixed 제거 (시도했지만 비채택 ❌)

**시도:**
```python
# is_mixed를 아예 제거
X_table = X_table.drop('is_mixed', axis=1)  # 7개 피처만
```

**결과:**
```
정확도: 83.3% → 82.1% (하락)
편향도: 11.7%p → 9.2%p (개선)
```

**판단:**
```
정확도 손실이 너무 큼 (1.2%p)
→ is_mixed 유지하되, 중요도만 낮춤
```

### 방법 3: Adversarial Debiasing (향후 고려)

**원리:**
```
모델이 is_mixed를 예측하지 못하도록
적대적 학습 추가

Loss = Classification Loss + λ × Debiasing Loss
```

**예상 효과:**
```
편향도: 11.7%p → 5%p 이하
정확도: 유지 또는 약간 하락
```

### 방법 4: Reweighting (향후 고려)

**원리:**
```
순종견 샘플의 가중치를 낮춤
믹스견 샘플의 가중치를 높임
```

**구현:**
```python
weights = [0.8 if is_mixed == 0 else 1.2 
           for is_mixed in df['is_mixed']]

model.fit(X, y, sample_weight=weights)
```

#### 클래스별

```
생존:

  차이: 6.9%p ✅

자연사:

  순종견: 2/3 = 66.7%
```

**해석:**

- 자연사: 샘플 너무 적어 불안정
- 안락사: 믹스견이 오히려 더 높음 (역편향?)

### 오류 케이스 분석

#### Case 1: 순종견 오예측

```
실제: 안락사
예측: 생존
이유: 이미지상 건강해 보임, 어려 보임

→ is_mixed=0 때문이 아니라 이미지 때문!
```

#### Case 2: 믹스견 오예측

```
실제: 생존
예측: 안락사
이유: 이미지 불량 (흐릿함), 나이들어 보임

→ is_mixed=1 때문이 아니라 이미지 품질 때문!
```

**결론:** 오예측 대부분이 is_mixed와 무관!

## 남은 편향 11.7%p의 의미

### 가설 1: 현실 반영 (긍정적)

```
실제로 순종견이 입양 확률이 약간 높을 수 있음
→ 귀여워 보임, 사람들의 선호

11.7%p는 현실적인 차이일 수 있음
```

### 가설 2: 데이터 편향 (부정적)

```
훈련 데이터 자체에 편향 존재
→ 순종견 생존 데이터가 더 많음

모델이 이를 학습했을 가능성
```

### 가설 3: 이미지 품질 차이

```
순종견 사진: 보호소에서 더 신경써서 촬영?
믹스견 사진: 상대적으로 품질 낮음?

→ 이미지 품질 차이가 편향으로 나타남
```

### 종합 판단

```
11.7%p는 허용 가능한 수준

이유:
1. XGBoost 25%p 대비 크게 감소
2. 실제 차이 5%p의 2배 정도
3. 완전한 0%는 현실적으로 어려움
4. is_mixed 피처가 거의 무시됨 (65위)
```

## 윤리적 고찰

### AI 공정성의 원칙

**1. Fairness (공정성)**
```
모든 개체가 품종과 무관하게
공정한 평가를 받아야 함

✅ 달성: is_mixed 중요도 98.7% 감소
```

**2. Transparency (투명성)**
```
모델이 어떻게 판단하는지
설명 가능해야 함

✅ 달성: 피처 중요도 분석 가능
⚠️ 한계: CNN 블랙박스
```

**3. Accountability (책임성)**
```
잘못된 예측에 대한 책임

✅ 달성: 83.3% 정확도
⚠️ 개선 필요: 자연사 클래스
```

### 실전 활용 시 고려사항

**1. 인간의 최종 판단**
```
AI는 보조 도구일 뿐
최종 결정은 인간이 내려야 함
```

**2. 지속적인 모니터링**
```
새로운 데이터에서도 편향이 없는지
주기적으로 확인
```

**3. 다양한 지표 사용**
```
정확도만이 아니라
공정성 지표도 함께 평가
```
